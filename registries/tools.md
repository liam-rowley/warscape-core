# Tools

Generated by `wsc reg render` from `registries/tools.jsonl`; do not edit. Change the rows with `wsc reg add|set` (or the JSONL) and re-render.

Every tool in the repo: a `wsc` verb, or a standalone script whose header says why it is not one. Rows are copied from file headers by `wsc reg add tools <path>`; the check fails when a row and its header drift.

5 rows. Search every registry: `wsc find <words>`.
